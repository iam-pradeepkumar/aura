The problem

When buildings fall and networks die, every minute counts.

No early warning

Communities often lack affordable, local systems that turn earthquake, storm, and flood data into actionable evacuations.

Rescue is blind

After collapse, USAR teams search huge rubble zones without knowing if anyone is alive inside a marked area.

Our solution

One alert node + four rescue nodes + your laptop. No internet router required for rescue.

⚠ Early warning

1 ESP32 alert node on public WiFi polls USGS & Open-Meteo. DM team approves alerts → webhook + nearby WiFi page with safe zones.

📡 Rescue sensing

4 RX + 1 TX join AURA_HUB after outage. Motion, count, position, vitals — fused on your laptop.

🖥 Dashboard

Simulation replay, live alert feed, and disaster-management console — all in one hand-drawn web app.

How it works

  1. Monitor — Alert node on community WiFi checks hazard APIs every 2 min.
  2. Verify — DM console reviews pending alerts; approve or reject.
  3. Warn — Approved alert → webhook to your team + LAN page for nearby phones.
  4. Failover — Network lost → alert node + rescue nodes join AURA_HUB.
  5. Rescue — field_live.py shows count, map, vitals in real time.

# Laptop hotspot

# Live sensing (close web dashboard first)
python3 tools/field_live.py
